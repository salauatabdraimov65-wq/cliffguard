## 2. Продукт в одном абзаце

**CliffGuard** — веб-сервис для самозанятых американских семей, которые сами покупают медстраховку на рынке ACA (Obamacare). С 2026 года вернулся «обрыв субсидий»: если доход семьи выше 400% федерального уровня бедности (FPL), государственная субсидия на страховку падает **до нуля**. CliffGuard показывает, сколько семья теряет, даёт **законный** план, как вернуть субсидию (взносы в SEP IRA / Solo 401(k) / HSA снижают MAGI), и весь год следит за доходом, чтобы семье не пришлось возвращать субсидию при подаче налогов.

**Питч одной фразой:** *Earn $1 more. Lose $10,500. We make sure that doesn't happen.*

## 3. Глоссарий (обязательно понимать)

| Термин | Значение |
|---|---|
| **ACA Marketplace** | Государственный рынок медстраховок (healthcare.gov + рынки штатов). Здесь покупают страховку те, у кого её нет от работодателя. |
| **Premium** | Цена страховки (ежемесячная/годовая). |
| **Benchmark silver plan (SLCSP)** | Второй по дешевизне «серебряный» план в районе. По его цене считается субсидия. Пользователь может купить любой план. |
| **Субсидия / PTC / APTC** | Premium Tax Credit — налоговый кредит на страховку. APTC — тот же кредит, выплачиваемый авансом каждый месяц по **прогнозу** дохода. |
| **FPL** | Federal Poverty Level — «линия бедности», зависит от размера семьи. |
| **MAGI** | Доход, по которому считается субсидия. Взносы в SEP IRA, Solo 401(k) (traditional), HSA его **уменьшают**. |
| **Cliff (обрыв)** | MAGI > 400% FPL → субсидия = $0. Даже если превышение $1. |
| **Applicable percentage** | Доля дохода, которую семья обязана платить сама за эталонный план (2027: от 2.15% до 10.22%). |
| **Reconciliation** | Сверка в налоговой декларации: реальный доход vs. прогноз. Переплату субсидии возвращают. |
| **Open enrollment** | Окно покупки страховки на следующий год. |

## 4. Формула (ядро продукта)

```
fpl              = FPL(household_size)                 // таблица HHS
cliff            = 4.0 * fpl
fpl_pct          = magi / fpl
if magi > cliff:   subsidy = 0
else:              applicable_pct = lookup(APPLICABLE_PCT_TABLE_2027, fpl_pct)
                   subsidy = max(0, benchmark_premium - applicable_pct * magi)
```

## 6. Пользователь (ICP)

- Самозанятые родители 30–45 лет, 1–3 ребёнка, покупают страховку на ACA, семейный доход ~$100k–150k, доход нерегулярный.
- **Демо-семья «Mike & Jess»:** Mike (38) — фрилансер-разработчик, Jess (36) — владелица кофейни, 2 детей, Austin, TX. Ожидаемый доход 2027 — **$136,000**. Эталонный план для семьи — **$24,000/год** (иллюстративно).
- Результат демо: граница $132,000 → превышение $4,000 → субсидия $0, потеря **~$10,510/год**. План: **$4,500 в SEP IRA** → MAGI $131,500 → субсидия **~$10,561**; оценка экономии фед. налога ~$990 (ставка 22%).

## 7. Пользовательский путь (MVP)

1. **Landing** — хук + «See what I'm losing — 60 sec» + «Try demo family».
2. **Quiz** (5 шагов): ZIP/штат → состав семьи и возраст → ожидаемый доход (+ опц. CSV) → тип занятости → цена эталонного плана (подсказка: healthcare.gov).
3. **Diagnosis** (бесплатно) — сколько теряешь + **интерактивный график с ползунком дохода** (главный «вау-момент» демо).
4. **Plan + Paywall** — первый шаг открыт, остальные под Pro ($99/год или $12.99/мес).
5. **Monitoring** (Pro) — «до обрыва осталось $X», напоминания (декабрь, перед подачей налогов).

## 8. Контракт данных (менять только по согласованию всей команды)

```ts
// src/lib/types.ts
export type Input = {
  householdSize: number;          // 1..8
  state: string;                  // "TX"; AK/HI -> unsupported в MVP
  zip?: string;
  ages: number[];                 // возраст каждого члена семьи
  income: number;                 // ожидаемый годовой доход (до пенс. взносов), USD
  netSelfEmploymentIncome: number;// для лимита SEP IRA
  benchmarkPremium: number;       // годовая цена эталонного серебряного плана, USD
  hsaEligible: boolean;           // выбран бронзовый/катастрофический план
  coverageYear: 2027;
};

export type PlanStep = {
  account: "SEP_IRA" | "SOLO_401K" | "HSA" | "MARKETPLACE_UPDATE";
  amount: number;                 // USD (0 для MARKETPLACE_UPDATE)
  deadline: string;               // человекочитаемо, EN
  note: string;                   // EN, 1 предложение
};

export type Result = {
  fpl: number;
  cliff: number;                  // 4 * fpl
  magi: number;
  fplPercent: number;             // 0..∞, напр. 4.12
  subsidy: number;                // текущая субсидия, USD/год
  overBy: number;                 // max(0, magi - cliff)
  loss: number;                   // сколько теряет из-за обрыва (0 если ниже)
  plan: PlanStep[];
  feasible: boolean;              // можно ли опуститься ниже обрыва в рамках лимитов
  contributionNeeded: number;
  magiAfterPlan: number;
  subsidyAfterPlan: number;
  estTaxSavings: number;          // оценка, 22% от взносов
  netBenefit: number;             // subsidyAfterPlan - subsidy + estTaxSavings
  warnings: string[];             // EN
};
```

1. **Не выдумывай цифры, законы и даты.** Только из раздела 5 или первоисточников (IRS, HHS, KFF, healthcare.gov). Новое — с ссылкой.

3. **Юридическая аккуратность:** продукт **не** продаёт страховку, **не** открывает счета, **не** двигает деньги, **не** даёт налоговых консультаций. Формулировки: «estimate», «educational», «confirm with a tax professional». Никогда: «guaranteed», «you will save».

5. **Не ломай контракт** (`types.ts`) без согласования.
6. Маленькие коммиты, понятные сообщения; `main` всегда деплоится.
7. Всё, что видно жюри, должно работать **без логина** и на мобильном.
